# Saffron Wonders landing page

Static one-page website, ready for GitHub Pages.

## Publish on GitHub Pages
1. Create a new GitHub repository (for example `saffron-wonders`).
2. Upload `index.html` and `style.css` to the repository root.
3. In GitHub: Settings → Pages → Build and deployment → Deploy from a branch → `main` / root.
4. Add your custom domain under Settings → Pages → Custom domain.

## Contact form
The form uses FormSubmit and sends submissions to `hello@saffronwonders.co.uk`.
On the first submission, FormSubmit may send an activation/confirmation email to that address. Confirm it once.

## Custom domain
GitHub will show the DNS records needed for your configuration. Configure them at your domain registrar, then enable HTTPS in GitHub Pages once DNS is active.
