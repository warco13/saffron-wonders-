# Saffron Wonders landing page — branded version

This version is styled from the supplied Saffron Wonders flyer and roller banner, including the purple/saffron palette, botanical artwork, logo motif and established messaging.

## Replace the current GitHub Pages site
Upload **all five files** in this folder to the root of the existing repository, replacing `index.html` and `style.css` when GitHub asks. Keep the three PNG files in the same root folder. GitHub Pages will redeploy automatically.

## Contact form
The form sends to `hello@saffronwonders.co.uk` through FormSubmit. The first submission may trigger an activation email that must be confirmed once.
